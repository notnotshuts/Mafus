# Contributing

Build on macOS with `./scripts/build.sh`. Keep user-visible claims aligned with FUNCTIONALITY.md. Never validate destructive changes against a physical device unless its owner explicitly authorizes that device and operation. Use temporary image files for automated tests.

Pull requests should explain the trigger, resulting behavior, meaningful validation and remaining hardware verification. New OS profiles must use official sources and architecture-specific ISO matching. Do not embed Windows or MS-DOS binaries in the repository.
