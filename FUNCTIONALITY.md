# Сопоставление со списком Rufus

Цель — нативное приложение **только для macOS**, без Windows-компьютера. «Реализовано» означает наличие рабочего кода и UI; это не подтверждение загрузки всех ОС или проверки на физических USB. Текущая версия ещё не покрывает весь присланный список. Не добавлены неработающие элементы интерфейса под видом готовых функций.

| Возможность | Статус Mafus |
|---|---|
| ISO / IMG, DD Mode | Реализовано; Linux ISO должен поддерживать прямую запись |
| Windows ISO Mode | Реализовано: извлечение Windows ISO на FAT32, UEFI |
| Linux Live USB | Реализовано через прямую запись подходящего образа |
| Windows To Go | Не реализовано: нужны применение на NTFS и создание корректной BCD-конфигурации |
| FreeDOS / MS-DOS | FreeDOS 1.4 LiteUSB: официальная загрузка с SHA-256 и запись IMG из ZIP. MS-DOS: собственный загрузочный IMG; генератор из системных файлов не реализован |
| Установка GRUB / Syslinux | Не реализовано; загрузчики готовых образов сохраняются при DD |
| UEFI:NTFS | Реализовано: NTFS-3G без FUSE, NTFS + отдельный FAT EFI-раздел, UEFI:NTFS 2.8; 512-байтные логические секторы |
| BIOS / UEFI / CSM | В DD — по возможностям образа; Windows FAT32 — UEFI, Windows NTFS/MBR — BIOS/CSM + UEFI при наличии BOOTMGR/BCD; ARM64 только UEFI |
| MBR / GPT | Реализовано для форматирования и Windows ISO; DD сохраняет схему образа |
| Secure Boot | Исходные EFI-файлы Windows сохраняются; проверка сертификатов/отзыва не реализована |
| EFI bootloader detection | Реализовано для Windows x64 / ARM64 / IA32 при подготовке |
| FAT16 / FAT32 / exFAT | Реализовано; FAT16 ограничен 2 GiB в текущей конфигурации |
| FAT12 / NTFS / UDF / ReFS / ext2 / ext3 | Форматирование этими системами не реализовано; исходные FS сохраняются в DD |
| Быстрое форматирование, метка, кластер | Реализовано для доступных режимов |
| BIOS загрузочный сектор | Сохраняется из IMG/ISO; BOOTMGR NTFS bootstrap и Windows-совместимый MBR добавляются в NTFS/MBR-режиме |
| Служебные разделы | Создаются системным менеджером разметки при GPT; произвольный редактор разделов отсутствует |
| WIM / ESD / SWM | Обработка встроенной wimlib, разбиение и конвертация; анализ редакций |
| Несколько редакций Windows | Сохраняются при подготовке установщика; просмотр сведений реализован |
| ISO download / Fido | 16 профилей Linux x64 / 8 ARM64 и прямые HTTPS-ссылки. Windows: получение временной ссылки через встроенную официальную страницу Microsoft и передача загрузки Mafus. PowerShell Fido не используется |
| Windows 11: TPM / Secure Boot / RAM / CPU | Генерация LabConfig в XML; эффект зависит от установщика, не проверен на ПК |
| Локальная учётная запись, имя, пароль | Генерация unattended LocalAccounts; пароль на USB хранится открыто |
| Microsoft Account / OOBE | Unattended-параметры локальной записи; универсальный обход новых OOBE не гарантируется |
| Язык, регион, часовой пояс | Явные поля в XML; настройки Windows не копируются из macOS автоматически |
| Приватность / BitLocker | Генерация документированных unattended-настроек |
| Windows CA 2023 / revocation / runtime validation | Не реализовано |
| Windows setup wrapper | Не реализовано |
| Quality of Life / Teams / Outlook / Copilot / OneDrive | Отдельные переключатели; provisioned/installed Appx, политики, штатный uninstall OneDrive; сценарии specialize/первого входа с журналами. Установка на ПК не проверена |
| Silent Installation / первый диск | Встроенного генератора нет; пользовательский XML может автоматизировать установку |
| SkuSiPolicy.p7b на ESP | При первом входе: файл установленной Windows → её ESP, сверка SHA-256 и снятие буквы. Выключено по умолчанию; последствия KB5042562 отражены в UI |
| Linux Persistence | Ubuntu Desktop / Debian Live / Linux Mint: ext4 1–128 GiB, метка, persistence.conf для Debian, параметры GRUB/ISOLINUX; 512-байтные сектора, неподдерживаемые ISO отклоняются |
| VHD | Сохранение и запись фиксированного VHD; служебный footer проверяется |
| Динамический VHD / VHDX / FFU | Не реализовано |
| Сжатые образы | Реализовано gzip, bzip2, xz и zstd для ISO/IMG; ZIP с одним ISO/IMG/VHD реализован; 7z не реализован |
| Save to IMG / VHD | Реализовано, весь USB; новые файлы, без перезаписи существующих |
| Save to ISO / UDF | Не реализовано |
| El Torito extraction | Не реализовано |
| Тест плохих блоков / ёмкости | Реализовано: полный разрушительный тест, 1–4 прохода |
| Проверка чтения / записи | Реализовано; ошибки ОС и несовпадения передаются в UI |
| Блокирующие процессы | Ошибки diskutil отображаются; отдельный анализ процессов не реализован |
| MD5 / SHA-1 / SHA-256 / SHA-512 | Реализовано |
| Журнал и сохранение между запусками | Реализовано |
| USB сведения / USB HDD / SSD | Внешние физические USB, имя, ёмкость, device ID; автоматическое обнаружение подключений и защита от подмены устройства по IOKit ID; подробная диагностика не реализована |
| Полное обнуление | Реализовано; это не firmware secure erase |
| Перезапуск USB-порта / VDS / VMware detection | Не реализовано; Windows-специфичные интерфейсы не используются |
| Скрытые переключатели Joliet / Rock Ridge / NTFS compression | Не реализовано |
| Портативное приложение | Реализовано: самостоятельный .app с встроенными wimlib, XZ и Zstandard |
| Простое UI и расширенные настройки | Компактный основной экран и боковое меню настроек; без TabView, наложений вкладок и вложенных областей прокрутки |
| Русский / английский / другие языки | UI на русском; полноценная локализация не реализована |
| Светлая / тёмная / системная тема | Реализовано |
| Liquid Glass | Настоящие API macOS 26+, системный материал на macOS 14–15 |
| Проверка обновлений | Не реализовано: у Mafus ещё нет опубликованного канала релизов |
| Прогресс / скорость / ETA | Прогресс, скорость и оценка оставшегося времени при известном объёме |
| Отмена | Между блоками/этапами; системные операции и WIM текущего этапа не прерываются |
| Горячие клавиши | Cmd+O/R/L/P и меню; полного набора скрытых комбинаций Rufus нет |
| Внутренние диски и отключение ограничений | Намеренно не доступны в текущем UI и Rust-ядре |

Список Rufus служит требованиями к развитию, а не заявлением о уже достигнутом паритете. ReFS и Windows API не входят в штатные инструменты macOS; NTFS, BOOTMGR BIOS/CSM и persistence для поддержанных Live ISO добавлены в 0.1.0. Windows To Go, генератор MS-DOS, универсальный GRUB/Syslinux installer и полноценная загрузочная проверка на физических ПК остаются вне текущей реализации.
