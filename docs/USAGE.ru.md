# Mafus 0.1.0

Mafus — нативная утилита macOS на SwiftUI с Rust-ядром для загрузочных USB, форматирования, резервного сохранения и диагностики. macOS 14+, Liquid Glass на macOS 26+; на старых системах используется системный материал. Сборка в этом каталоге — Apple Silicon.

## Запуск и сборка

```sh
open dist/Mafus.app
```

Для сборки нужны Swift Command Line Tools и Cargo в PATH. Полный Xcode не обязателен. Встроенные wimlib, XZ, Zstandard, NTFS-3G, xorriso и e2fsprogs собираются из приложенного исходного архива; Homebrew не требуется.

```sh
./scripts/build.sh
```

Скрипт проверяет Rust-ядро, Swift-код и преобразование ESD/WIM/SWM, затем создаёт и подписывает `dist/Mafus.app`. Для публичного распространения нужны Developer ID и notarization; эта сборка подписана локально.

## Основной сценарий

Выберите образ и внешнее USB-устройство, нажмите «Создать загрузочный USB», подтвердите стирание и системный запрос прав администратора. В автоматическом режиме приложение монтирует ISO только для чтения и определяет установочный Windows ISO по его структуре. Каталог открывается кнопкой «Скачать ISO» рядом с выбором файла. Параметры и инструменты доступны по кнопке рядом с описанием режима; разделы находятся в боковом меню с одной областью прокрутки.

- **Windows FAT32:** копирование файлов, загрузка UEFI. Большой `install.wim` разбивается в `install.swm`, `install2.swm` и далее. Большой `install.esd` сначала преобразуется в WIM без solid-сжатия. Целостность boot.wim и установочного WIM/ESD/SWM проверяется до стирания USB, включая подготовленные SWM. Все редакции WIM сохраняются; их перечень можно посмотреть в параметрах.
- **Windows NTFS:** отдельная NTFS-партиция и FAT-раздел с подписанными EFI-компонентами UEFI:NTFS 2.8. WIM/ESD не разбиваются. NTFS подготавливается во временном образе без FUSE, копирование файлов проверяется до записи USB. GPT или MBR для UEFI; **BIOS/CSM + UEFI** требует MBR и BIOS-файлы BOOTMGR/BCD в ISO. Для ARM64 BIOS запрещён. Поддерживаются накопители с логическими секторами 512 байт. Доверие Secure Boot зависит от прошивки и списка отзыва.
- **Linux:** прямая запись гибридного ISO / IMG с сохранением загрузчиков, разметки и файловых систем исходного образа. BIOS/UEFI/Secure Boot зависят от самого образа. Произвольный незагрузочный ISO не превращается в загрузочный.
- **Linux Persistence:** Ubuntu Desktop, Debian Live и Linux Mint. Размер 1–128 GiB, отдельный ext4-раздел с меткой `writable` для casper или `persistence` для Debian, где создаётся `/ union` в `persistence.conf`. xorriso изменяет Live-пункты в GRUB/ISOLINUX и воспроизводит загрузочные структуры ISO. GPT переносится на конец USB с пересчётом CRC. Неподдерживаемые ISO и недостаточная ёмкость отклоняются до изменения USB. Параметр 0 отключает persistence. Сектор USB — 512 байт.
- **FreeDOS:** кнопка в инструментах загружает официальный FreeDOS 1.4 LiteUSB ZIP и проверяет SHA-256. Это установочный носитель FreeDOS; выбранный ZIP автоматически распаковывается при записи. BIOS/CSM, x86.
- **MS-DOS:** запись собственного лицензированного загрузочного IMG. Генерации MS-DOS из каталога системных файлов и встроенных файлов Microsoft DOS нет. Тип загрузки определяется исходным IMG.
- **ZIP:** архив должен содержать ровно один ISO, IMG или фиксированный VHD. Образ извлекается потоково в отдельный файл с ограничением размера; ссылки, опасные пути и неоднозначные архивы отклоняются.
- **IMG / фиксированный VHD:** прямая запись; служебный footer VHD не попадает на накопитель. Динамический VHD и VHDX не поддерживаются.
- **Gzip / bzip2 / XZ / Zstandard:** сжатые ISO и IMG распаковываются во временное место на внутреннем диске с прогрессом и отменой. Размер распаковки ограничен ёмкостью USB; для XZ/Zstandard память ограничена 512 MiB. Выбор файла не запускает полную распаковку.
- **Секторы 4 KiB:** хвост прямой записи дополняется нулями до границы сектора и проверяется при обратном чтении.

Образы и файлы ответа должны находиться на внутреннем диске Mac. Это предотвращает размонтирование источника при подготовке USB. Для конвертации ESD, разделения WIM и распаковки требуется дополнительное свободное место на внутреннем диске. Бинарники не обращаются к USB для записи в ходе файловых тестов.

## Параметры

- MBR / GPT, метка тома длиной 1–11 латинских букв, цифр, дефиса или подчёркивания.
- FAT16 (накопители до 2 GiB), FAT32, exFAT; автоматический размер кластера или 4/8/16/32 KiB для FAT.
- Windows FAT32 использует разбиение WIM; NTFS включается отдельно в разделе Windows. В прямом режиме Linux эти параметры не меняют разметку исходного образа.
- Проверка записанных данных побайтовым чтением с отключением кеширования.
- Оформление по системе, светлое или тёмное; уменьшение движения и прозрачности учитывает настройки доступности macOS.

## Настройка Windows

Приложение может сформировать `autounattend.xml`: LabConfig для аппаратных проверок, локальная учётная запись, язык/регион, часовой пояс Windows, пропуск вопросов о конфиденциальности и отключение автоматического шифрования устройства. Архитектура компонента подставляется по EFI-загрузчику образа. Совместимость и эффект этих настроек зависят от версии установщика; загрузка и установка Windows на реальном ПК в этой сессии не проверялись.

Пароль локальной учётной записи хранится в файле ответа на USB в открытом виде; пустой пароль создаёт пользователя без пароля. Пользовательский XML может быть в UTF-8 или UTF-16 с BOM; структура и пространство имён проверяются до записи. Временный файл на Mac имеет права 0600 и удаляется после операции. Собственный XML заменяет встроенные настройки и может содержать автоматическое стирание диска компьютера. Приложение не добавляет автоматическое стирание целевого компьютера по умолчанию и не перезаписывает уже существующий в ISO файл ответа.

Дополнительные переключатели Windows применяются через `autounattend.xml` и сценарии в `sources/$OEM$/$$/Setup/Scripts`. Teams, новый Outlook и Copilot удаляются из provisioned Appx и установленных Appx-пакетов; для Copilot применяется политика, OneDrive отключается политикой и штатным uninstall. «Меньше рекомендаций» отключает Fast Startup, потребительские предложения, новости и Bing в поиске. Результаты пишутся в `%WINDIR%/Temp/Mafus-specialize.log` и `Mafus-first-logon.log`. Эффект зависит от версии и редакции Windows; политики некоторых редакций могут игнорироваться.

**SkuSiPolicy.p7b на ESP** — отдельная опция, выключенная по умолчанию. При первом входе сценарий берёт файл только из `%WINDIR%/System32/SecureBootUpdates` установленной системы, назначает свободную букву её ESP, копирует в `EFI/Microsoft/Boot`, проверяет SHA-256 и снимает букву в `finally`. Если файла или ESP нет, ошибка остаётся в журнале. По [KB5042562](https://support.microsoft.com/help/5042562) применение этой политики блокирует откат VBS-компонентов и может сделать старые загрузочные/восстановительные носители несовместимыми. Mafus не подставляет политику иной версии и не изменяет ESP самого Mac.

Свой XML полностью заменяет встроенные настройки, включая QoL и SkuSiPolicy.

## Инструменты

- Форматирование внешнего USB.
- Сохранение всех блоков USB в IMG или фиксированный VHD на внутренний диск; при ошибке неполный образ удаляется. Существующие файлы не перезаписываются.
- Проверка чтения всего накопителя без изменения данных.
- Разрушительный тест записи и последующего чтения, 1–4 прохода, с адресно-зависимым шаблоном для обнаружения ошибок и поддельной ёмкости.
- Полное обнуление с опциональной проверкой. Обнуление не является гарантированным secure erase флеш-памяти.
- MD5, SHA-1, SHA-256, SHA-512 выбранного образа; MD5 и SHA-1 предназначены для совместимости с опубликованными суммами.
- Каталог из 16 вариантов Linux ISO для x64 и 8 вариантов для ARM64: Ubuntu, Ubuntu Server, Kubuntu, Xubuntu, Lubuntu, Debian, Debian Live, Fedora Workstation/KDE, Mint Cinnamon, Arch, openSUSE Tumbleweed, Alpine, Kali, Rocky и AlmaLinux.
- Прямые загрузки с официальных серверов и зеркал: поиск актуального ISO, прогресс, отмена, сверка опубликованной SHA-256 при наличии. Версии Ubuntu закреплены на ветке 26.04 LTS, Rocky/Alma — на ветке 10; патч-релизы и поддержанные rolling/stable выпуски определяются по метаданным.
- Windows 11 x64/ARM64: встроенная официальная страница Microsoft. После выбора выпуска и языка нажатие ISO-ссылки открывает диалог сохранения Mafus и запускает встроенный загрузчик. Постоянные или сторонние ссылки Microsoft не зашиты.
- После загрузки образ автоматически выбран для записи. Своя прямая HTTPS-ссылка тоже поддерживается.
- Автоматическое обновление списка при подключении и отключении накопителя. Проверка идентификатора текущего подключения предотвращает запись на другое устройство с повторно использованным номером диска.
- Скорость и оценка оставшегося времени на этапах с известным объёмом. Mac не засыпает при выполнении операций с USB.
- Параметры записи сохраняются между запусками; пароль Windows не сохраняется в настройках.
- Журнал, экспорт и опциональное сохранение между запусками.
- Отмена между блоками или по завершении текущего системного этапа. Разметка, монтирование и обработка WIM не прерываются посередине. После отмены записи USB может быть незагрузочным.

## Проверенные границы

Приложение отклоняет внутренние диски и отдельные разделы; перед запросом прав администратора и внутри ядра повторно проверяет метаданные и идентификатор подключения устройства. Проверены сборка, подпись, временные файловые тесты, контрольные суммы, преобразование ESD → WIM → SWM с обратным извлечением и распознавание синтетического Windows ISO через настоящее монтирование macOS.

Каталог проверен по действующим метаданным: все 16 вариантов x64 и 8 ARM64 нашли ISO. Официальный процесс Microsoft проверен до получения ссылки русского Windows ISO и открытия диалога сохранения Mafus; многогигабайтные образы полностью не скачивались. Совпадение SHA-256 обеспечивает проверку целостности по опубликованной сумме, но не заменяет проверку GPG-подписей манифеста. Доступность серверов и временных ссылок может меняться.

На реальном USB не проверялись форматирование, запись, восстановление, тесты блоков или загрузка ОС. Windows XML проверен на экранирование и отсутствие неявного стирания диска, но не прошёл Windows SIM и установку на реальной машине. Проверены NTFS-каталоги, EFI/OEM-файлы с чтением через ntfscat, NTFS MBR/GPT и BOOTMGR-код, ZIP с ограничением ёмкости, модификация двух синтетических Live ISO с ext4, `persistence.conf`, El Torito BIOS/UEFI и переносом GPT. Синтаксис сценариев проверен PowerShell на Mac. Эти проверки не заменяют запуск Windows Setup и перезагрузку реального Linux USB. Это разработческая сборка, не полный функциональный эквивалент Rufus. Полный список различий: [FUNCTIONALITY.md](../FUNCTIONALITY.md).

## Архитектура

`Sources/Mafus` — SwiftUI и системные диалоги; `core/src` — образы, устройства, Windows и инструменты; `vendor` — исходники и лицензии зависимостей; `Tests` — файловые проверки. `.app` содержит самостоятельные `mafus-core`, `wimlib-imagex`, `xz`, `zstd`, `mkntfs`, `ntfs-populate`, `xorriso` и `mke2fs`, исходники и лицензии зависимостей. wimlib распространяется под GPLv3+. Запись выполняется отдельным процессом через системный запрос прав администратора; приложение не устанавливает фонового root-демона.

Документация: [Liquid Glass](https://developer.apple.com/documentation/swiftui/view/glasseffect(_:in:)), [подготовка Windows USB и SWM](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/install-windows-from-a-usb-flash-drive?view=windows-11), [wimlib](https://wimlib.net/), [Rufus FAQ](https://github.com/pbatard/rufus/wiki/FAQ).
