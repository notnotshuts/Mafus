Mafus 0.2.1 fixes USB synchronization and the format-to-copy transition on macOS.

- Raw USB writes flush the device through DKIOCSYNCHRONIZECACHE, avoiding unsupported file-only F_FULLFSYNC and error 25.
- File synchronization falls back to POSIX fsync only when full synchronization is unsupported. Real I/O failures still stop the operation.
- FAT32/FAT16/exFAT formatting waits for the selected partition to mount.
- Windows copying and verification hold the volume open and detect a disappeared or replaced mount point before continuing.
- The redesigned Next.js website has accessible shadcn/ui controls, both themes, architecture selection and automatic GitHub release links.

Choose the Apple Silicon (arm64) or Intel (x86_64) ZIP for your Mac. macOS 14+ is required. SHA256SUMS.txt covers all ZIPs.

Experimental release: ad hoc signature, no notarization. Regression and file-based integration tests passed; the user's physical USB was not formatted or flashed during development. Raw ISO/IMG writing intentionally requires the USB to be unmounted while data is written.
