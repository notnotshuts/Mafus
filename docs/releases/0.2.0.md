Mafus 0.2.0 adds 24 interface languages, native Intel builds and a simpler website.

- 254 localized application messages, system language detection and an in-app language selector. Translations are bundled and work offline.
- Native Apple Silicon (`arm64`) and Intel (`x86_64`) packages, including all USB preparation tools.
- Animated settings and operation transitions, with support for macOS Reduce Motion.
- Smaller SwiftUI components and separate image, device, download and operation modules.
- The website offers dark/light themes, always-visible Duck/Utya GIFs from official Telegram resources and current download links from GitHub Releases.
- USB devices refresh after an operation. Packaged translations and executable architectures are checked during the build.

Choose the ZIP matching your Mac. Both packages require macOS 14+. SHA256SUMS.txt covers the release ZIPs. The source archive contains third-party source and license files.

This is an experimental release with an ad hoc signature and no notarization. File-based tests and CI builds do not confirm physical USB boot, Windows Setup or Linux persistence after a hardware reboot. Machine-assisted translations still welcome native-speaker corrections. Technical output from external tools remains in its original language.
