# Changelog

## 0.2.1 — 2026-10-13

- Исправлена ошибка `Inappropriate ioctl for device (os error 25)` при синхронизации USB на macOS: raw-устройства используют DKIOCSYNCHRONIZECACHE вместо файлового F_FULLFSYNC.
- Для файловых систем без F_FULLFSYNC используется POSIX fsync; ошибки ввода-вывода продолжают прерывать операцию.
- После форматирования FAT32/FAT16/exFAT программа ожидает появления и монтирования выбранного раздела.
- Том удерживается открытым до завершения копирования Windows и проверки данных. Исчезновение/замена точки монтирования останавливает запись.
- Полностью обновлён сайт: Next.js, shadcn/ui, светлая/тёмная темы, адаптивная вёрстка и автоматические ссылки на релизы.

## 0.2.0 — 2026-10-13

- 24 языка, полный набор из 254 сообщений и переключение языка без перезапуска.
- Нативные arm64 и x86_64 сборки, проверка архитектуры всех bundled executables.
- Тёмный сайт, переключение темы, Duck/Utya GIF из официальных ресурсов Telegram.
- Автоматический выбор актуальных GitHub Release assets, кэш и fallback при сетевой ошибке.
- Разделение SwiftUI страниц и модели на отдельные компоненты.
- Переходы настроек и состояний, анимация поиска USB с учётом Reduce Motion.
- Исправлено обновление USB после завершения операции.
- Локализации устанавливаются в стандартный Resources каталог приложения.

## 0.1.0 — 2026-10-13

Первый публичный экспериментальный релиз.

- SwiftUI интерфейс, системные диалоги, темы, Liquid Glass на macOS 26+.
- Rust-ядро, проверка внешнего физического USB и идентификатора подключения, подтверждение стирания.
- Windows FAT32 с обработкой WIM/ESD/SWM, NTFS/UEFI:NTFS, BIOS/CSM BOOTMGR.
- Linux DD и persistence для Ubuntu Desktop, Debian Live и Linux Mint.
- FreeDOS LiteUSB download, DOS IMG и ограниченное извлечение ZIP.
- Windows unattended, QoL и установка SkuSiPolicy на ESP при первом входе.
- Каталог Windows/Linux ISO, прогресс и SHA-256 при наличии опубликованной суммы.
- Backup, проверки блоков/чтения, обнуление, контрольные суммы, журнал, отмена и ETA.

Сборка ad hoc, без notarization. Проверка физических USB и загрузки реальных ОС ещё требуется. Подробные границы — FUNCTIONALITY.md.
